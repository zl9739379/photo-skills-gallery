<small>Photo Skills Gallery</small>

<small>A showcase of the same photo (Chengdu Meinian Plaza) processed by all **8 AI photo-processing skills** from WorkBuddy's library "Photo Space".</small>

- **生成模型 / Model**：OpenAI gpt-image-2（本地脚本 `gpt_image_2.py` / local script `gpt_image_2.py`）
- **输出方式 / Output**：每个技能独立输出，不拼接原图 / each skill outputs a standalone result, no source stitching
- **在线展示 / Live demo**：https://zl9739379.github.io/photo-skills-gallery/
